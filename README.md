# LandChain - Simple Version

LandChain is a college project prototype for a blockchain-based land registry.

## Technologies
- Python
- Flask
- HTML
- CSS
- SHA-256
- JSON

## Run
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000/

Demo login:
- Username: admin
- Password: admin123

## Important
This is a custom Python blockchain prototype. It is not a deployed Ethereum/Solidity smart-contract application and is not a legal government land registry.
